# Ahmed Hdhili Portfolio

Static portfolio website for Ahmed Hdhili, Web Developer.

## Files

- `index.html` - Main portfolio page
- `styles.css` - Responsive styling
- `script.js` - Small dynamic footer year script
- `assets/ahmed-hdhili-avatar.jpg` - Hero profile image

## How to publish

Upload all files in this folder to any static hosting provider.

For GitHub Pages:

1. Create a new GitHub repository.
2. Upload the contents of this folder.
3. Go to `Settings > Pages`.
4. Select the main branch and root folder.
5. Save, then wait for GitHub Pages to publish the site.
